# PACEBREAK 0.3.48

A free bicycle-racing arcade game for personal entertainment. Virtual coins have no cash value and cannot be redeemed. The game has no deposits, withdrawals, real-money wagers, or cash prizes.

## Download and play

1. Open the [v0.3.48 release](../../releases/tag/v0.3.48) and download `PACEBREAK-0.3.48-RC2-release-review-2026-11-17.zip` and its `.sha256` sidecar.
2. Verify the downloaded ZIP with PowerShell:

   ```powershell
   Get-FileHash .\PACEBREAK-0.3.48-RC2-release-review-2026-11-17.zip -Algorithm SHA256
   ```

   Compare the result with the value in the sidecar.
3. Extract the ZIP, keep `PACEBREAK-0.3.48.exe` beside its `assets` folder, and run it on Windows 10 or Windows 11 desktop. The build targets .NET Framework 4.8 Windows Forms.
